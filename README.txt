NEST — INSTALLABLE MOBILE WEB APP (PWA)

1. Upload the contents of this folder to an HTTPS static website (e.g. Render static site, Netlify, GitHub Pages). Keep folder layout unchanged.
2. On iPhone: open the HTTPS address in Safari, tap Share > Add to Home Screen > Add.
3. On Android: open the HTTPS address in Chrome, tap ⋮ > Install app / Add to Home screen.
4. Launch Nest from your home screen.

Important: This ZIP is a ready-to-host PWA package, NOT an Android APK or an iOS App Store file. Opening index.html directly from Downloads may not offer installation or offline caching. HTTPS hosting is necessary for reliable install.
Data is stored in local browser/app storage and does NOT automatically sync across phones. Export backups from Settings before changing devices.
